# 영어 단어 시험지 생성기

영어 단어와 한글 뜻을 입력하여 시험지와 정답지를 PDF로 생성하는 GUI 애플리케이션입니다.

## 기능

- **사용자 정의 제목**: 시험지 제목을 직접 입력 가능 (예: "Unit 20", "Unit 21")
- 영어 단어와 한글 뜻을 쉽게 입력
- 입력된 단어 목록을 테이블 형태로 표시
- 단어 추가/삭제/전체 삭제 기능
- **단어 섞기 기능**: 시험지에서 단어 순서를 랜덤하게 섞어서 배치
- 시험지와 정답지를 하나의 PDF 파일로 생성
- 4열 구조 (영어 단어 / 뜻 쓰는 공백란 / 영어 단어 / 뜻 쓰는 공백란)

## 설치 및 실행

### 1. 필요한 패키지 설치

```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행

```bash
python quiz_generator.py
```

## 사용법

1. **제목 입력**: 시험지 제목을 입력 (예: "Unit 20", "Unit 21", "Chapter 5" 등)
2. **단어 입력**: 영어 단어와 한글 뜻을 입력하고 "단어 추가" 버튼을 클릭
3. **단어 관리**: 
   - 선택된 단어 삭제: 목록에서 단어를 선택하고 "선택된 단어 삭제" 버튼 클릭
   - 전체 삭제: "전체 삭제" 버튼으로 모든 단어 삭제
4. **단어 섞기**: "단어 섞기" 버튼을 클릭하여 단어 순서를 랜덤하게 섞기
5. **PDF 생성**: "PDF 생성" 버튼을 클릭하여 시험지와 정답지를 포함한 PDF 파일 생성

## 생성되는 PDF 구조

### 시험지 (1-2페이지)
- 4열 구조: 영어 단어 / 뜻 쓰는 공백란 / 영어 단어 / 뜻 쓰는 공백란
- 영어 단어는 표시되지만 뜻은 공백으로 표시
- 시험지가 1페이지에서 끝나면 2페이지는 공백으로 유지

### 정답지 (3-4페이지)
- 4열 구조: 영어 단어 / 뜻들 / 영어 단어 / 뜻들
- 영어 단어와 모든 뜻이 표시됨
- **시험지와 동일한 단어 순서**: 시험지에서 섞인 순서 그대로 정답지에도 적용
- 인쇄 시 편리하도록 별도 페이지로 구성

## 단축키
